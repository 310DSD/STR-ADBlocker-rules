# False-positive-prone hostname families, one lowercase substring token per
# line. Comments start with '#'.
#
# These are ad-monetised vendor ecosystems whose *functional* hosts (login,
# push, HTTPDNS, CDN, mini-program assets, camera/cloud, store, telemetry of
# the vendor itself) have repeatedly been mis-listed by single providers and
# then blocked, breaking real functionality on device.
#
# A hostname containing any token below must be listed by at least
# SENSITIVE_MIN_PROVIDER_MATCHES providers before it enters the ruleset;
# every other hostname only needs MIN_PROVIDER_MATCHES. The compiled rules are
# therefore the union of all providers, with this list acting as the only
# place where extra source agreement is required.
#
# Keep tokens specific enough not to collide with unrelated registrations
# (e.g. ".mob.com" does not match "admob.com").
