# Rule category tokens. Format: "<category> <token>".
#
# A token matches a DNS label when the label equals the token, starts with
# "<token>-", or is "<token>" followed only by digits (for example "ads3").
# Matching is case-insensitive and applies to every label of the hostname.
#
# Categories:
#   ad        1  kernel-enforced everywhere (DNS + connection), not per-app
#   tracker   2  userspace-enforced at connection layer, per-app profile
#   telemetry 3  userspace-enforced at connection layer, per-app profile
#   functional 4 never blocked (diagnostic only; should be allowlisted)
#
# Anything unmatched stays "unknown" (0) and is treated like "ad" for kernel
# enforcement, so a missing classification never weakens blocking.
